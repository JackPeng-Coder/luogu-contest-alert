# 洛谷比赛监控提醒工具 (Luogu Contest Alert)

一个轻量级、智能且高效的 Python 桌面程序，专门用于监控洛谷（Luogu）平台上的比赛状态。支持竞赛开始/结束时弹出提醒，提供美观的 PySide6 图形界面和系统托盘。

---

## 🚀 功能特性

### 智能监控
- 🔍 自动抓取洛谷比赛列表，深度适配洛谷新版 HTML/JSON 数据结构
- 🕐 每整点和半点自动检查，延迟 5 秒避免边界竞争
- 🛡️ 全流程异常捕获 + 请求自动重试，确保持续稳定运行

### 丰富提醒
- 🔔 **弹窗提醒**：精美 TKinter 通知窗口，支持一键跳转比赛详情页
- 💬 **系统托盘消息**：PySide6 原生托盘气泡通知
- 🏁 **比赛开始/结束**：分别检测 `未开始 → 进行中` 和 `进行中 → 已结束` 两种状态变更
- 🚫 防重复弹窗机制

### 现代 GUI（默认模式）
- 🎨 PySide6 图形界面，自定义无边框窗口 + 渐变标题栏
- 🔘 自定义动画开关控件，iOS 风格切换
- 📋 弹窗提醒、消息提醒、开始/结束提醒独立开关
- 🖥️ 系统托盘图标，右键菜单列出所有设置开关
- 🔄 所有设置实时持久化到 `data/settings.json`
- 🪟 窗口关闭自动最小化到托盘

### 系统集成
- 📝 完善日志（控制台 + 文件双输出）
- 🔌 开机自启动（注册表方式，Windows）
- 💾 本地 JSON 持久化（比赛状态 + 用户设置）
- 🎯 `Ctrl+C` 安全退出（CLI 模式）

## 📖 使用方法

### GUI 模式（默认）
带有图形设置界面和系统托盘，适合日常使用：
```bash
python main.py
```
窗口关闭自动最小化到系统托盘，双击托盘图标恢复。

### CLI 模式（控制台）
纯命令行运行，适合调试或在无桌面环境的服务器使用：
```bash
python main.py --cli
```

### 后台静默运行
使用 `pythonw` 隐藏控制台窗口在后台持续工作：
```bash
pythonw main.py
```

### 设置开机自启动
在 GUI 模式 → 常规设置 → 勾选「开机自启动」即可。

## 🧠 工作原理

1. **初始化**：程序启动时加载本地历史数据和用户设置，立即执行首次抓取。
2. **状态比对**：
   - 定时（整点/半点）从洛谷抓取最新的比赛列表。
   - 将当前状态与本地存储的状态进行比对。
   - 识别出状态从 `未开始 → 进行中`（比赛开始）或 `进行中 → 已结束`（比赛结束）的比赛。
3. **触发提醒**：根据用户设置，选择弹窗窗口、系统托盘消息或两者同时通知。
4. **数据同步**：将最新的比赛状态写回本地 JSON 文件，进入下一个等待循环。
