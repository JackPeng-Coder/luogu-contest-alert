# 洛谷比赛监控提醒工具 (Luogu Contest Alert)

一个轻量级、智能且高效的 Python 后台程序，专门用于监控洛谷（Luogu）平台上的比赛状态。当比赛状态从 **“未开始”** 切换为 **“进行中”** 时，程序会自动弹出美观的桌面通知窗口，确保你不会错过任何一场精彩的比赛。

---

## 🚀 功能特性

- 🔍 **智能监控**：自动抓取洛谷比赛列表，深度适配洛谷最新版 HTML/JSON 数据结构。
- 🔔 **实时提醒**：比赛开始瞬间弹出基于 Tkinter 的原生通知窗口，支持一键跳转至比赛详情页。
- ⏰ **提前提醒**：可在设置中配置比赛开始前 / 结束前（5/15/30/60 分钟）的提前提醒。
- ⏱️ **动态调度**：按比赛触发点（提前提醒、开始、结束）精准对齐检查时间，无临近触发点时自动回退轮询。
- 💾 **状态持久化**：使用本地 JSON 数据库（`data/contests.json`）存储比赛状态，精准识别状态变更；已发送提醒跨重启不重复。
- 📝 **完善日志**：集成 Python `logging` 模块，同时支持控制台输出与本地文件记录（`logs/app.log`）。
- 🛡️ **健壮性设计**：
  - **异常处理**：全流程异常捕获，确保程序不会因单次抓取失败而崩溃。
  - **重试机制**：网络波动时自动重试，提高抓取成功率。
  - **优雅退出**：支持 `Ctrl+C` 及系统信号（SIGINT/SIGTERM）安全退出。
- 🎨 **免配置运行**：开箱即用，自动创建所需的数据与日志目录。

## 📖 使用方法

### 前台运行 (开发调试)
在控制台中运行，可实时查看程序运行日志：
```bash
python main.py
```

### 后台静默运行
使用 `pythonw` 运行，程序将隐藏控制台窗口在后台持续工作：
```bash
pythonw main.py
```

### 设置开机自启动 (Windows)
1. 为 `main.py` 创建一个桌面快捷方式。
2. 右键该快捷方式 -> **属性** -> **目标**。
3. 在路径最前面添加 `pythonw`（例如：`pythonw "C:\path\to\main.py"`）。
4. 按下 `Win + R` 键，输入 `shell:startup` 并回车。
5. 将修改好的快捷方式拖入弹出的文件夹中即可。

## 🧠 工作原理

1. **初始化**：程序启动时加载本地历史数据，并立即执行首次抓取。
2. **动态调度**：每次检查后计算最近的比赛触发点（开始前提前提醒 / 开始 / 结束前提前提醒 / 结束），精准睡到那一刻；无临近触发点时回退到固定间隔轮询。
3. **状态比对**：
   - 从洛谷抓取最新的比赛列表，将当前状态与本地存储的状态进行比对。
   - 识别提前提醒（未开始且进入提前窗口 / 进行中且临近结束）与状态切换（`未开始`→`进行中`、`进行中`→`已结束`）。
   - 已发送的提醒记录在比赛的 `sent_reminders` 字段中，跨重启不重复。
4. **触发提醒**：检测到提醒事件后，调用 `notifier` 弹出窗口（弹窗）与系统托盘消息（GUI 模式）。
5. **数据同步**：将最新的比赛状态与提醒记录写回本地 JSON 文件，并进入下一个调度循环。
